  `Err`/`ok_or`/`ok_or_else`, `map_err`, indirect expression, or match pattern.
- `#[cfg(test)] mod` ranges are excluded by independent token/delimiter and sanitized-source
  brace walks. Test expectations are not runtime emission sites.
- Step/move enum names, `FAMILY_OF` rows, family ownership totals, per-family
  `IMPLEMENTED` rows, and `coverage.json` must agree exactly.
- Snapshot provenance is pinned to `44062b41a4d2525fa9991f0ffa5b8c68c3311956` rather than a moving Git merge-base;
  the self-test simulates an advanced HEAD and requires the generated provenance to stay fixed.
- `--self-test` mutation-controls Python under-match and Rust comment/test/pattern/emitter
  classification. There is deliberately no artifact `--check`: this is a frozen one-time
  measurement, and `--write` is reserved for an explicit remeasurement decision.
